# Strm Assistant · Emby 4.10 增强版

面向 **Emby Server 4.10.2** 的插件构建，在社区版基础上补齐了一批与中文媒体库、STRM 播放、多版本管理相关的能力。非官方项目，个人维护。

- 适配程序集版本：`4.10.2.0`（Emby 4.10.2 稳定版）
- 支持平台：Linux x64 / arm64、macOS
- 许可证：GPL-3.0

---

## 这个项目解决什么问题

如果媒体库是「STRM 指向云端 + 中英文混排条目 + 同片多版本」这种形态，原生 Emby 有几处会难受：起播慢、中文搜不到、多版本挤在一起、片头跳过要每集算。这个构建针对这些点做增强。

本构建从社区的 Strm Assistant 项目延续而来（社区版见[上游仓库](https://github.com/sjtuross/StrmAssistant)），在其之上继续开发；能力清单见下。

## 能力清单

### 播放与扫描

- 同目录多版本自动合并，合并上限可调到 2–64（原生上限 8）
- 多版本按画质（分辨率/码率）排序，显示名可选「媒体信息风格」或「强制文件名」
- 跨媒体库的多版本分别记录播放进度与收藏，互不覆盖
- STRM 场景优化起播：媒体信息提取、截图、BIF 可持久化，重扫不必重算

### 中文使用体验

- 搜索支持拼音全拼、拼音首字母、繁简互搜、别名与原名、演员名
- 搜索结果按匹配质量分级排序（精确 > 前缀 > 包含 > 模糊），并过滤不可见条目
- 中文元数据补全：豆瓣简介/海报/演员/导演/季集，可关闭、可限速
- 简繁海报与徽标区分，备选语言可设「优先繁中 + 简转繁」
- 插件界面、设置页、任务名均为中文（含繁体）

### 元数据与刮削

- **本地 TMDB 元数据源**：指定一个本地根目录，形成 `cache/`（被动缓存）与 `override/`（人工覆盖）两层
  - 四种模式：优先缓存 / 在线刮削并缓存 / 仅用覆盖缓存 / 关闭
  - 覆盖层支持按 `tmdbid` 只改想改的字段（标题、简介、海报等），未提供的字段仍走在线
  - 支持 `episodegroup.json` 定义本地剧集组（不需要剧集组 ID）
  - 支持 `tags.json` 追加自定义标签
  - 支持统一内容分级、自定义特别篇播出顺序
- 剧集组刮削、原语言海报、替代 TMDB 地址、备选语言顺序
- 元数据/图像更新通知（可选）、合集条目变更通知

### 媒体信息

- ISO / BDMV 内视频的媒体信息提取（UDF 回退 ISO9660、mpls 与 DVD IFO 章节）
- 杜比视界双层（Profile 7）检测，可分辨 MEL / FEL 并显示在标签
- HDR Vivid 识别、Atmos / DTS:X 音频标识
- 截图后处理：按横屏 16:9 / 竖屏 2:3 校正比例
- 可指定自定义 ffmpeg 与参数（例如解决 DV P5 截图发绿）
- 提取黑名单：按标签或关键字跳过指定条目（媒体信息 / 声纹 / BIF 三套独立）

### 片头片尾与字幕

- 按媒体库配置声纹探测时长，支持并行计算
- 片头片尾数据可接外部库（含第二数据源）
- 外挂字幕扫描，并可同时扫描外挂音轨
- 针对 STRM 优化 OpenSubtitles 的搜索与下载路径

### 扩展

- 可选 rffmpeg sidecar：把 `ffprobe` 调用经 SSH 分发到 worker 节点（见 `docs/rffmpeg-deployment.md`）
- 分布式媒体信息提取：插件自身发起的信息提取可下发给 worker，失败自动回落本地并分类统计

## 安装

1. **确认版本**：Emby 4.10.2，程序集 `4.10.2.0`。版本不一致会被拒绝加载（日志报 `LoaderException: Could not load ... Version=public-ip-xxx`）。
2. **备份**现有插件目录。
3. 把发布包内 `plugins/` 的内容整体拷入 Emby 插件目录，保持如下结构：
   ```
   plugins/
   ├── StrmAssistantLite.dll
   ├── StrmAssistantLite.deps/        依赖程序集（缺一不可）
   ├── zh/StrmAssistantLite.resources.dll
   └── zh-hant/StrmAssistantLite.resources.dll
   ```
4. **重启** Emby（运行中替换 DLL 不生效）。

设置文件为 `Strm Assistant.json`，从旧版本升级不会丢配置；回滚只需还原备份的 DLL 再重启。

## 常用设置位置

- 插件开关：**设置 → 高级 → Strm 助手**
- 任务：**设置 → 计划任务**（搜索索引重建、媒体信息提取、演员刷新、豆瓣缓存预构建等）
- 本地元数据源：填「本地元数据根目录」后自动创建 `cache/` 与 `override/` 结构

多数增强项**默认关闭**，建议按需开启；涉及前端注入或补丁的项目一次只开一个，观察一段时间再加下一个。

## 已知限制

- 同目录多版本合并的 **8 部上限**在 Emby 扫描端是硬编码的，插件只能调整任务侧上限
- 播放进度在 Emby 原生按 TMDB ID 共享，跨版本分离由插件自行记录并接管续播
- 不接管 Emby 的转码链路
- 杜比视界 P7 的分层检测需要外部 ffprobe ≥ 9（Emby 自带 5.1 不支持）
- 豆瓣、IntroDB、OpenSubtitles 均为第三方数据源，限流或接口变化会导致对应功能暂时不可用
